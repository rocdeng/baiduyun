# 百度网盘助手

一个面向百度网盘网页端的油猴脚本，用于生成百度网盘文件的直链下载命令。当前版本号：`1.0.28`，作者：`Roc Deng`。

## 当前版本定位

| 项目 | 说明 |
|---|---|
| 支持网盘 | 仅保留百度网盘 |
| 主下载方式 | 生成 `aria2c` 命令并自动复制到剪切板 |
| 辅助方式 | 保留 JSON-RPC 推送与 IINA 播放 |
| 不再支持 | 已移除阿里云相关逻辑，不再调用 IDM 等外部下载器 |
| 已移除功能 | 已移除 cURL、比特彗星下载菜单及对应生成逻辑 |
| 远程配置 | 已移除 `api.youxiaohou.com` 远程下发配置，必要配置改为本地常量和本地存储 |
| 外部说明页 | 已清理 `www.youxiaohou.com` 引导、说明类超链 |

## 主要改动

| 模块 | 改动 |
|---|---|
| 安全清理 | 移除远程配置接口，减少脚本启动时对第三方服务器的依赖 |
| 配置方式 | 百度 OAuth `client_id/appkey` 改为本地设置项，可填写自己的百度应用 AppKey |
| 下载链路 | Aria 下载生成成功后自动复制完整 `aria2c` 命令 |
| 跨平台复制 | 自动识别浏览器所在系统；Mac 保留原命令格式，Windows 生成 PowerShell 兼容的 `aria2c.exe` 命令并默认保存到 `D:\` |
| Windows Cookie 兼容 | 同时兼容新版 `GM_cookie.list(...)` 和旧式 `GM_cookie('list', ...)`，避免因未读取到 BDUSS 而生成空命令 |
| 原生接管 | 接管百度网盘文件行自带的“下载”按钮，点击后走 Aria 生成流程 |
| 文件选择 | 点击文件行下载时自动选中该文件，复制成功后自动取消选中 |
| 批量更名预览 | Season 和删除字符分别提供启用勾选项；支持数字或 `E+数字` 开头的 Episode 文件名，删除字符按字面匹配且保留扩展名前的点，预览窗口可现场修改规则并刷新 |
| 智能改名 | 自动从文件名提取 Episode 编号并生成 `SxxExx` 名称；预览结果可点击原地编辑，按 Enter 保存后再确认更名 |
| 界面优化 | 主弹窗、设置框、提示框、文件列表按 Ant Design 风格重新整理 |
| 横向设置布局 | 设置窗口改为宽屏双栏布局，连接设置使用三列网格，外观与页面过滤并排显示 |
| 页面清理 | 助手设置中可按行添加多个 CSS 选择器，自动删除匹配的广告 DIV 或其他页面元素；默认保留现有广告与云一朵过滤规则 |
| 名称图标 | 脚本名称改为“百度网盘助手”，作者改为“Roc Deng”，并内置清新的 Apple 风格 PNG 图标 |
| IINA 播放 | 视频播放页和下载助手菜单均可获取带时效签名的原始地址，并携带必要请求头交给 IINA |
| 稳定性优化 | 清理无效依赖与死代码，合并页面过滤扫描，为网络请求增加超时，并支持主题色即时切换 |

## 使用方式

| 操作 | 说明 |
|---|---|
| 单文件下载 | 鼠标移到文件行，点击百度网盘原生“下载”图标 |
| 批量生成 | 勾选多个文件后，使用顶部“下载助手”菜单里的 Aria 下载 |
| 批量智能改名 | 勾选多个文件后进入“批量更名”，点击“智能改名”生成预览；可点击新文件名原地编辑并按 Enter 保存 |
| Aria 使用 | Mac 自动复制 `aria2c` 命令；Windows 自动复制 PowerShell 可执行的 `aria2c.exe` 命令，文件默认保存到 `D:\` 根目录 |
| 文件夹 | 文件夹不能直接生成 Aria 链接，需要进入文件夹后选择具体文件 |
| AppKey | 在助手设置里填写自己的百度应用 AppKey 后，再按提示完成 OAuth 授权 |
| IINA 播放 | 可在视频播放页点击右上角按钮，或在文件列表中选中一个视频后使用下载助手菜单 |

## 安全说明

| 项目 | 说明 |
|---|---|
| 百度接口 | 直链生成使用百度官方域名接口，包括 `pan.baidu.com` 与 `openapi.baidu.com` |
| BDUSS | 生成 Aria 命令时会读取本机浏览器中的 `BDUSS`，并作为 `Cookie` 请求头写入命令 |
| Access Token | OAuth 授权后得到的 `access_token` 会保存在本地脚本存储中 |
| 第三方远程 | 已去除启动时必须访问第三方配置服务器的逻辑 |
| 命令风险 | 复制出的命令包含下载链接、文件名、BDUSS，请不要发给他人 |

## 依赖

| 项目 | 说明 |
|---|---|
| 脚本管理器 | Tampermonkey |
| 浏览器 | Chrome、Edge 等支持 Tampermonkey 的现代浏览器 |
| 下载工具 | 推荐本地安装 `aria2c` |
| 外部播放 | 使用播放页按钮需在 macOS 安装 IINA |

## 注意事项

| 场景 | 说明 |
|---|---|
| 浏览器直接下载 | 百度直链在浏览器中直接访问可能返回未授权，当前推荐使用 Aria 命令 |
| 会员速度 | 下载速度仍受百度账号、会员状态、网络环境和 Aria 配置影响 |
| 页面结构变更 | 百度网盘网页 DOM 变化后，原生下载按钮接管可能需要跟进适配 |
